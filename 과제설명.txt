1. 과제 개요
본 과제는 물리 시뮬레이션 환경 기반의 랜덤 팔레타이징(Random Palletizing) 알고리즘을 개발하는 것을 목표로 합니다. 다양한 크기와 질량의 박스가 무작위 순서로 공급되는 환경에서, 제한된 버퍼를 활용하여 적재 효율을 최대화하는 박스 선택 및 적재 순서 최적화 전략을 구현해야 합니다.

개발된 알고리즘은 NVIDIA Isaac Sim 기반의 물리 엔진 위에서 실행되며, 박스의 질량·충돌·마찰 등 물리 속성을 고려한 적재 안정성까지 검증됩니다. 따라서 단순히 부피를 채우는 것을 넘어, 무너지지 않고 안정적으로 쌓이는 패턴을 도출하는 것이 핵심입니다.

본 과제는 물류센터 자동화 환경에서의 실제 적재 문제를 모사한 것으로, 적재율 향상은 운송 비용 절감과 공간 효율화로 직결되는 산업적 가치를 가집니다.

4. ⛔ 필수 경고 — 패키지 사용 제한 / 프로세싱 시간 제한
참가자가 사용하는 모든 패키지는 당사에서 제공하는 requirements.txt에 명시된 패키지로 한정됩니다. 제공된 requirements.txt 외의 패키지를 사용할 경우, 평가 환경에서 코드가 정상적으로 구동되지 않아 채점이 불가능합니다. 반드시 제공된 환경 내에서 동작하는 코드만 제출해 주시기 바랍니다.
프로세싱 시간은 데이터셋 1개 기준 최대 90초를 초과할 수 없습니다.

5. 알고리즘 제한 조건
적재했던 박스는 다시 버퍼 / 팔레트로 적재 불가
버퍼는 최대 20개 박스 저장 가능, 사용 개수가 적을수록 가산점 부여
버퍼 사용 개수는 프로세스 시작 시 1회만 설정되며, 이후 변경 불가
버퍼 동작: 버퍼에서 박스를 하나 사용하면 새로운 박스 1개가 자동 보충됨
박스는 랜덤한 순서로 제공됨
AI 모델 사용 시 ONNX 형식 기반 모델만 사용 가능

6. 프로그램 출력 규격
출력은 적재 패턴 sequence를 JSON 파일로 생성 (단, 입력된 박스를 모두 쌓지 않아도 됨)
포함해야 할 데이터: Box ID, 적재 위치 (x, y, z), 방향 (rotation)
팔레트의 좌하단 모서리를 (0, 0, 0) 으로 정의
적재 좌표: 박스의 centroid (무게중심) (x, y, z)
방향: rotation ∈ {0°, 90°}
팔레트 크기는 가로 1,000 × 세로 1,200 mm 이며 최대 적재 높이는 1,250 mm 임.

출력 JSON 생성 및 저장 기능은 템플릿 소스 코드에 포함되어 있으며, 참가자는 제공된 API 및 저장 구조를 사용하는 것을 권장합니다.
출력 포맷을 임의로 변경할 경우 정상 평가가 수행되지 않을 수 있습니다.

8. 평가 기준
제출한 소스 파일은 당사 PC 환경에서 실행되며, 적재율 및 적재 성공 여부를 기준으로 평가합니다.
평가 데이터는 매 실행 시 새롭게 랜덤 생성되며, 물리 엔진 기반 시뮬레이션 환경에서 검증됩니다.

- 중간 평가 (리더보드)
    리더보드 평가는 참가자가 제출한 코드를 대상으로 공개 데이터 2세트와 비공개 데이터 1세트에 대해 수행됩니다.

- 최종 평가
    최종 평가는 참가자가 최종 제출한 코드를 대상으로 비공개 데이터 5세트에 대해 수행됩니다.

    평가 항목	세부 내용	반영 비율
    적재율 + 적재 성공	아래 세부 기준 참조	100%
    적재율 측정
    ∑in Volume of Stacked_Boxi
    Cubic volume
    (Cubic volume = 1,000 × 1,200 × 1,250 mm³)

- 버퍼 사용에 대한 추가 점수
    버퍼 미사용 시 +20
    버퍼 1개 사용 시 +19
    버퍼 20개 모두 사용 시 추가 점수 없음
    팔레트 적재 Condition (Pass / Fail)
    하나의 박스라도 팔레트 영역을 벗어나면 해당 팔레트는 적재 실패(Fail)로 판정됩니다.
    팔레트 최대 적재 높이인 1,250 mm를 초과하면 해당 팔레트는 적재 실패(Fail)로 판정됩니다.
    적재 중 박스가 드랍(drop)되거나 무너지면 해당 팔레트는 적재 실패(Fail)로 판정됩니다.
    → Fail 판정을 받은 팔레트는 해당 팔레트에 한하여 0점 처리됩니다.

- 최종 점수 산정
    최대 점수는 120점이며, 적재율과 버퍼 사용량을 종합적으로 평가합니다.
    적재율 100% 달성 시 100점, 버퍼 미사용 시 추가 20점이 부여됩니다.
    참가자는 최종 획득 점수를 기준으로 평가됩니다.
